# HG2054 Essay Supplementary Materials

This repository contains supplementary materials for my HG2054 *Pragmatics of AI Language* essay examining whether discourse-particle choice affects DeepSeek's politeness classifications of matched Colloquial Malay utterances.

## Repository Structure

### `Code/`

- `MalayPrag_MinimalPairs.gs`  
  Google Apps Script used to identify matched *kan–ke* minimal pairs from the MalayPrag dataset and generate corresponding null forms.

- `HG2054_Essay_API.ipynb`  
  Google Colab notebook used to submit the resulting utterances to the DeepSeek API under direct zero-shot and generic Chain-of-Thought (CoT) prompting conditions.

### `Data/`

- `Minimal Triplets.csv`  
  The final set of 28 *kan–ke–null* triplets used in the experiment, comprising 84 utterances in total.

- `Direct_vs_CoT.csv`  
  Full DeepSeek classification output for all 84 utterances under both prompting conditions, including whether the Direct and CoT classifications were identical.

### `Prompts/`

Contains the exact prompt templates used for the Direct and CoT conditions.

## Experimental Setup

Each utterance was submitted independently to the DeepSeek API using the `deepseek-flash` model.

Two prompting conditions were tested:

1. Direct zero-shot prompting
2. Generic Chain-of-Thought (CoT) prompting

For both conditions, the model assigned one of three politeness labels:

- `Polite`
- `Impolite`
- `Neutral`

Generation settings were held constant across conditions:

- `temperature = 0`
- `top_p = 0.1`

## Dataset Source

The experimental stimuli were derived from the MalayPrag dataset:

Mariah Al Giptiah Binte Yusoff, Tan, J., Chen, B., Liu, G., & Chen, X. (2026). *Can large language models handle discourse particles? A case study of Colloquial Malay*. arXiv:2605.28782.

## Reproducibility Note

The null condition was generated by removing the discourse particle from the corresponding lexical frame. The resulting triplets were used to test whether DeepSeek's categorical politeness judgements changed when particle choice was manipulated while propositional content was held approximately constant.

These materials are provided for transparency and reproducibility of the HG2054 essay analysis.
